Data jsou jenom zaznamenany kus cehokoliv, surove upraveny a samy o sobě nic uzitecneho neříkají
Informace jsou data obohacena o to co znamenaji
Myšlenka i.e. tapír ma 37.5°C ale je to zdrava? Potřebuju informaci druhou kolik má zdravou

Reprezentace údajů se dela pomoci datovych typu int long short float double string
Jake rozmezi potřebujeme pro data takový volíme typ

Operatory (funkce) umozni operace nad daty
Jsou unarni, binarni, ternarni

Kategorie cleneni:
1.
Homogenni pole prvku - pole stejných prvku
Heterogenní - data různých struktur (typů)

2.
Staticka - nemuzou se menit
Dynamicka - meni se
Usporadany binarni strom lze promenit v oboustranne provazany seznam

Datove struktury:
Pole - uklada hodnoty stejného typu ma dopredu danou velikost kterou nelze jednoduše změnit prisutpuje se primo pomoci indexu 

Vyhody jsou jendoduchost rychlost snadnost
Nevyhody jsou ze je potreba znát velikost dopredu

Typ znak:
Umoznuje reprezentaci znaku i.e pismeno cislici oddelovace
Retezec je pole znaků 

Typova kontrola
Navrh struktur je tvoreni vlastního datového typu
Vetsinu veci se osetri kompilátorem díky typu 

Kazdy objekt (konstanta promenna vyraz funkce) prislusi jednomu datovemu typu
